# Blockhaven

ブラウザだけで遊べる、Three.js と TypeScript 製のボクセル・サンドボックスです。

## 遊び方

```bash
npm install
npm run dev
```

- **WASD**: 移動、**Space**: ジャンプ、**Shift**: ダッシュ
- **マウス**: 視点移動、左クリックで採掘、右クリックで設置
- **1〜6 / ホイール**: ブロック選択、**Esc**: ポーズ

地形はシードから自動生成され、変更したワールドはブラウザの LocalStorage に自動保存されます。

## 開発

```bash
npm test
npm run build
```

本作は独自の名称・表示素材を使用したオリジナル作品で、Minecraft および Mojang Studios とは関係ありません。
